💰 Mis Gastos

Sistema web para registrar, administrar y controlar gastos personales, desarrollado con Python, Flask y SQLite.

📌 Descripción del proyecto

Mis Gastos es una aplicación web que permite al usuario gestionar sus gastos personales de manera sencilla y organizada.

El sistema permite registrar nuevos gastos, consultar el historial, editar o eliminar registros y visualizar el total acumulado.

Este proyecto fue desarrollado como una aplicación práctica para aplicar conocimientos de programación web, bases de datos y pruebas de software.

✨ Funcionalidades

- Registro de gastos personales.
- Consulta del historial de gastos.
- Edición de gastos registrados.
- Eliminación de gastos.
- Cálculo automático del total acumulado.
- Almacenamiento de información mediante SQLite.
- Pruebas de funcionamiento del sistema.

🛠️ Tecnologías utilizadas

Tecnología| Uso
Python| Lenguaje de programación
Flask| Framework web
SQLite| Base de datos

⚙️ Instalación y ejecución

1. Clonar el repositorio

git clone URL_DEL_REPOSITORIO

2. Entrar a la carpeta del proyecto

cd sistema_gastos

3. Instalar Flask

pip install flask

4. Ejecutar la aplicación

python app.py

5. Abrir en el navegador

http://127.0.0.1:5000

🧪 Pruebas

El proyecto incluye un archivo "test_app.py" para realizar pruebas del funcionamiento de la aplicación.
